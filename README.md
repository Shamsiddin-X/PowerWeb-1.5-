# PowerWeb 1.5.1

Визуальный редактор сайтов на React, TypeScript, Zustand и Tauri. Работает в браузере и как настольное приложение. Позволяет собирать страницы на холсте, сохранять переносимые проекты `.pwb` и экспортировать самостоятельные HTML- или React-сайты.

## Возможности

- Страницы и слои, фигуры, текст, изображения, видео и импорт шрифтов.
- Группировка, буфер обмена, привязки, масштабирование и история до 200 состояний.
- Несколько анимаций одного объекта, визуальные шейдеры и логика событий.
- PWB 2: ZIP-контейнер с документом, медиа, шрифтами, шейдерами и миниатюрой; чтение старых JSON-проектов.
- HTML/CSS/JS и React-экспорт с ресурсами, семантической разметкой и настраиваемой мобильной раскладкой.
- Недавние документы и восстановление через IndexedDB; сохранение языка, темы и настроек интерфейса.

## Быстрый запуск

Требуется **Node.js 22+** и npm. Выполняйте команды из корня репозитория.

```bash
git clone https://github.com/Shamsiddin-X/PowerWeb-1.5-.git
cd PowerWeb-1.5-
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Сервер использует строгий порт: если 3000 занят, остановите другой процесс или измените `server.port` в `vite.config.ts`.

Для веб-версии ключи API и файл `.env` не нужны.

### Настольное приложение

Дополнительно нужны Rust, Cargo и системные зависимости Tauri 2 для целевой ОС. На Linux используются GTK 3 и WebKitGTK 4.1; точный набор пакетов зависит от дистрибутива.

```bash
npm run tauri dev
npm run tauri build
```

Сборки для каждой ОС создаются в подходящем окружении. Артефакты Tauri находятся в `src-tauri/target/release/bundle/`.

## Проверки и сборка

```bash
npm test                  # Все наборы тестов
npm run typecheck         # Проверка TypeScript
npm run build             # TypeScript + production-сборка в dist/
npm run check             # Тесты + сборка
npm run format:check      # Оформление документации, тестов и CI
npm run preview           # Локальный просмотр собранной веб-версии
```

GitHub Actions выполняет установку через `npm ci`, проверку оформления, тесты и веб-сборку. Команды Rust, отдельные наборы тестов и ручной приёмочный сценарий описаны в [руководстве по тестированию](docs/testing.md).

## Ограничения

Мобильная компоновка использует базовую вертикальную раскладку: сложные макеты требуют настройки групп и брейкпоинтов. Внешние медиа должны быть доступны для скачивания с разрешённым CORS; надёжнее импортировать файл. Копии в IndexedDB зависят от квоты браузера и не заменяют ручное сохранение `.pwb`.

Тесты проверяют модель, файловые форматы, экспорт и часть поведения UI. Визуальное совпадение, реальные GPU/WebGL, нативные диалоги и установщики требуют ручного прогона. Локальные JS-плагины исполняются как доверенный код.
